ELKAYAM CINEMA Private rclone

A personal local workflow for saving lawfully held files in the account owner’s private Google Drive library. rclone runs on the owner’s computer. Offline viewing requires files on the viewing device.

This is an informational static site only: no sign-in, media, forms, tracking scripts, application API or Drive access. Independent of Google and AIOStreams.

Privacy policy

Privacy policy

Effective 19 October 2026. This policy covers the personal ELKAYAM CINEMA Private rclone OAuth client and local workflow.

Access and use

After the owner authorizes access, local rclone uploads selected lawfully held files, lists permitted destinations, checks sizes and hashes, and reads files back to verify integrity. The intended least-privilege scope is drive.file. Additional access is not silently requested. Actual access is defined by Google consent.

Storage and sharing

Files are kept in the owner’s private Google Drive and local staging. OAuth credentials stay in protected local storage, including the operating-system keychain and encrypted configuration. Local receipts may retain file paths, hashes, identifiers and transfer status. No Drive files, tokens or private library records are published here. Google processes API requests and stores files under its own policies.

Google user data is not sold, used for advertising, disclosed to unrelated parties or used to train AI models. Use of Google API data follows the Google API Services User Data Policy, including Limited Use requirements. Local cleanup applies only to explicitly authorized workflow files after verification.

Control and retention

The owner can stop the workflow, revoke access in Google Account third-party connections and remove local configuration and receipts. These remain until the owner removes them. Revocation does not delete files stored in Drive; the owner manages those directly. No public registration or third-party user service is offered. The owner maintains this personal application locally; this informational site can be contacted through its repository.

Website hosting

No application analytics, forms or tracking scripts are used. GitHub Pages may process ordinary connection information under GitHub’s privacy policy.
